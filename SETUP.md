# Setup

1. Create/use the GitHub profile repository `shobhit-pixel/shobhit-pixel`.
2. Copy all files from this package into the repository root.
3. Commit and push to the `main` branch.
4. Open the Actions tab and run **Generate contribution snake** once.
5. GitHub will automatically render `README.md` on your profile.

The hero banner has both light and dark SVG variants and already embeds the supplied portrait.
